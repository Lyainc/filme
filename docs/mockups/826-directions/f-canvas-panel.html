F 캔버스 + 문맥 패널

결합안 · C 뼈대 + A 패널

화면

파란 숫자 핀은 아래 "요구 6개 수용" 표의 번호예요. 티켓은 비율만 맞춘 자리표시예요.

구현 메모

  • 패널은 target만 받는 ContextPanel 하나에 대상별 본문(티켓·필드·포스터·로고)을 모듈 최상위 컴포넌트로 나눠 둬요. 컴포넌트 안에서 컴포넌트를 정의하면 대상이 바뀔 때마다 본문이 다시 마운트돼요.
  • 선택 대상과 접힘/펼침은 셸(MobileEditorShell)이 쥐고, 슬라이더를 끄는 동안의 값은 ref나 본문 로컬 state에 두었다가 놓을 때 한 번만 문서 state에 반영해요.
  • 티켓 렌더러는 memo로 감싸고 선택 테두리는 티켓 밖 오버레이로 그려요. 대상을 바꿔도 무드 트리가 다시 그려지지 않고, 저장물과 화면이 같은 노드로 남아요.
  • 접힘과 펼침은 조건부 마운트가 아니라 같은 깊이의 노드에서 높이만 바꿔요. 무드 썸네일은 가벼운 정적 프리뷰로, KOBIS 결과·자르기 모달은 쓰일 때 동적 import로 불러요.
  • 제목 입력은 그대로 두고 KOBIS 결과 목록만 useDeferredValue로 늦춰 타이핑이 밀리지 않게 해요.
