E 캔버스 + 도구 색인

결합안 · C 뼈대 + A 탭

화면

파란 숫자 핀은 아래 "요구 6개 수용" 표의 번호예요. 티켓은 비율만 맞춘 자리표시예요.

구현 메모

  • 선택 상태(지금 대상)는 셸 하나가 쥐고, 색인 탭·문맥 툴바·꾸미기 패널은 그 값에서 파생해요. 탭 점등을 effect로 맞추지 않고 렌더 중에 계산해요.
  • 티켓 렌더러는 memo로 떼고 선택 테두리·툴바는 티켓 DOM 바깥 오버레이 형제로 둬요. 선택이 바뀌어도 티켓이 다시 그려지지 않고 저장 노드도 깨끗해요.
  • 슬라이더 드래그 중 값은 ref·로컬 상태로 들고 놓을 때 문서에 반영해요. 매 프레임 문서 setState는 티켓 전체 리렌더예요.
  • 꾸미기 패널(무드 썸네일 6장 포함)과 입력 시트의 KOBIS 결과는 열 때 동적 import로 불러요. 첫 화면 번들엔 캔버스·색인만 들어가요.
  • 툴바·패널 컴포넌트는 셸 파일 최상위에 정의하고(컴포넌트 안 정의 금지), 핸들러는 함수형 setState로 안정시켜 색인 6탭이 같이 리렌더되지 않게 해요.
