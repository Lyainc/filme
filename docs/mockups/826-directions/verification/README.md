# 방향 목업 렌더 확인 (2026-11-15)

Aside(사용자 브라우저, CLI 1.26.1113.1717)의 `aside repl`로 방향 페이지 여섯 개(A~D + 결합안 E·F)와 비교 페이지를 393×852, 375×812 뷰포트에서 열고 화면(`.screen`)마다 재고 찍었어요. 실기기·iOS Simulator·헤드리스 하네스 결과가 아니에요. Android는 #585 보류라 다루지 않아요.

## 재는 것 (`verify-aside.js`)

- 문서 가로 넘침: `scrollWidth - innerWidth`
- 화면 가로 넘침: `.screen`의 `scrollWidth - clientWidth`
- 잘림: 요소가 가장 가까운 `overflow` 조상 밖으로 걸치는지. 스크롤 축(auto/scroll)은 의도된 스크롤이라 제외하고, 티켓 자리표시 내부·키보드 자리표시·숨은 캐러셀 슬라이드는 제외
- 조작부끼리 겹침: button·input·a·select·switch·tab·chip 쌍의 교차 면적. 각 사각형은 클리핑 조상과 교차시킨 "보이는 부분"으로 재요(내부 스크롤로 접힌 행을 겹침으로 잡지 않게)
- 요구 핀이 글자를 가리는지: 핀과 텍스트 노드 사각형의 교차
- 글자가 다른 요소에 덮였는지: 글자 사각형 중심에서 가장 위에 그려진 요소(`elementFromPoint`)가 그 글자 자신인지. 조작부끼리 겹침 검사가 못 보는 "티켓 자리표시가 라벨을 덮는" 경우를 잡아요. 내부 스크롤 영역에서 접혀 안 보이는 행과 모달 scrim은 제외해요
- 요구 핀 1~6이 페이지에 모두 있는지, 원칙 단락·요구표·기능 보존표가 그려졌는지

## 진행 중 고친 것

첫 측정과 requirement-gap 리뷰 1라운드에서 나온 결함은 고친 뒤 다시 쟀어요.

- A 디자인 패널(리뷰 지적): 썸네일 칸을 80px로 줄인 뒤 티켓 썸네일이 폭 기준이라 높이가 넘쳐 무드 이름 위쪽을 덮었는데, 당시 검사는 조작부끼리만 봐서 "전부 통과"로 기록했어요. 썸네일 티켓을 칸 높이에 맞추고, 위의 글자 덮임 검사를 더해 다시 쟀어요
- A 디자인 패널: "빈 항목 보기" 행이 252px 패널 아래로 잘림 → 무드 썸네일 칸 높이를 96px에서 80px로 줄임
- A·B·D: 요구 핀이 슬라이더 값, 입력, 안내문 글자를 가림 → 위치를 옮김
- A·B·C·D: 재질·코팅 칩과 슬라이더 라벨이 현재 앱과 다름(무광·엠보·금박·광택·매트 등) → 현재 앱 값(재질 원본·미술용지·빈티지·흑백 신문, 코팅 없음·유광·홀로그램·메탈릭·스코딕스, 재질 강도·코팅 강도)으로 맞춤

- E·F 폴리싱(소유자 요청, hallmark audit + react-best-practices): 아이콘·텍스트 중복, pill·그림자·말풍선 꼬리 같은 장식, 같은 무게의 버튼 나열, 강조색 남용을 덜고 글자 크기를 11/13/15/17로 정리한 뒤 다시 쟀어요. 결과는 위 표와 같아요

## 파일

- `shots/dark-{방향}-{폭}-{화면번호}.png`: 다크(Aside 시스템 테마) 393·375
- `shots/light-{방향}-375-{화면번호}.png`: 라이트 강제 375
- `report-dark-393-375.json`, `report-light-375.json`: 화면별 측정값
- `verify-aside.js`, `decode.py`: 다시 재는 법. 이 디렉터리를 `uv run --no-project python -m http.server 4826 --bind 127.0.0.1`로 띄운 뒤 `aside repl --file verify-aside.js > run.log` 하고 `python3 -I decode.py run.log out/`으로 PNG를 풀어요. Aside REPL은 프로젝트 밖에 파일을 못 써서 스크린샷을 base64로 stdout에 흘려요.

## 확인하지 않은 것

- 320px 폭과 가로 회전
- 실제 소프트 키보드와 VisualViewport 동작(키보드는 회색 자리표시)
- 터치 조작감(트랙 드래그·hit area)은 그림으로만 표시했어요. 실기기 검증은 시드 단계의 일이에요.
