선택 표시 · 세리프 · 브릭 범위

세 결정을 같은 자리표시 티켓 위에 그렸어요. 각 후보는 다크·라이트 무대를 나란히 놓았고, 추천안은 테두리를 한 단계 진하게 했어요. 확정된 것: 테마는 시스템 설정을 따르고, 글꼴은 mono 없이 Pretendard Variable 하나로 가요(숫자는 고정폭 숫자 설정만).

4. 세리프를 어디에 쓸지

워드마크는 BI 마스터 v2 락업(클래퍼 티켓 마크 + Nunito 900 "fılme")을 그대로 둬요. f-refined가 세리프를 썼던 자리는 워드마크 대체였는데, 그 대체를 걷으면 세리프가 남는 자리는 랜딩 헤드라인 하나예요. 한글 세리프는 웹폰트를 하나 더 들여야 해요(여기선 Noto Serif KR 600으로 그렸어요).

5. 브릭을 어디까지 쓸지
