## 현재 상태

번들 로고는 저작권 문제로 배포에서 뺐다(#231). 사용자가 필드 에디터의
Theater/Format 스탬프 행에서 직접 업로드하는 방식으로 대체됐다.

로고 원본을 두던 `chains/`, `formats/`, `메가박스_BI/`는 **로컬 보관용이라 gitignore 대상**이라서
새로 clone하면 없다.
